🛒 Supermarket Sales Analysis Dashboard

📌 Project Overview

The Supermarket Sales Analysis Dashboard is an interactive Excel-based data analysis project designed to analyze supermarket sales data and generate meaningful business insights. The project focuses on understanding sales performance across different product categories, outlet types, and outlet locations.

Using Microsoft Excel, the dataset is cleaned, transformed, analyzed, and presented through an interactive dashboard containing key performance indicators (KPIs), charts, and slicers. The analysis helps identify sales trends, compare outlet performance, and support data-driven business decisions.

🎯 Project Objectives

The main objectives of this project are:

- Analyze total sales and average sales performance.
- Identify the highest- and lowest-performing product categories.
- Compare sales performance across different outlets.
- Analyze sales contributions by outlet location tiers.
- Understand the relationship between product visibility and sales.
- Compare sales based on item fat content.
- Calculate statistical measures such as mean, median, minimum, maximum, and standard deviation.
- Identify potential sales outliers using the IQR method.
- Present key findings through an interactive dashboard.

🛠️ Tools & Technologies Used

- Microsoft Excel
- PivotTables and PivotCharts
- Excel Formulas and Functions
- Slicers for interactive filtering
- Data Cleaning and Transformation
- Statistical Analysis

📊 Project Workflow

1. Data Cleaning and Transformation

- Reviewed and cleaned the raw supermarket sales dataset.
- Standardized inconsistent item fat content labels.
- Handled missing item weight values using the median weight for the corresponding item type.
- Created additional calculated fields for better analysis.
- Prepared the dataset for further analysis.

2. Data Analysis and Calculations

- Calculated total sales, average sales, and average item visibility.
- Analyzed sales performance across product categories and outlets.
- Compared sales across outlet types and location tiers.
- Calculated mean, median, minimum, maximum, and standard deviation.
- Used the Interquartile Range (IQR) method to identify potential outliers.

3. Dashboard Development

- Created KPI cards to display important business metrics.
- Developed interactive charts using PivotCharts.
- Added slicers to filter and explore the data.
- Designed a dashboard to present important sales trends and comparisons.

4. Business Insights

- Identified the highest- and lowest-selling product categories.
- Compared the performance of individual outlets.
- Analyzed sales variation across product categories.
- Evaluated outlet performance across location tiers.
- Examined the distribution of sales and potential outliers.

🔍 Key Business Insights

Based on the analysis:

- Total Sales: 1,201,681.49
- Average Sales: 140.99
- Average Item Visibility: 0.0661
- Total Records: 8,523
- Highest-Selling Category: Fruits and Vegetables
- Lowest-Selling Category: Seafood
- Highest-Selling Outlet: OUT035
- Lowest-Selling Outlet: OUT019
- Highest Sales Variation: Dairy
- Lowest Sales Variation: Baking Goods
- Highest-Performing Outlet Type: Supermarket Type 1
- Lowest-Performing Outlet Type: Supermarket Type 3
- Top-Performing Location Tier: Tier 3
- Outlier Analysis: No outliers were identified using the 1.5 × IQR method.
